## What I build

I like the layer where an idea stops being a demo and starts becoming a system:

- **AI agents & LLM infrastructure** — tool use, memory, MCP, model routing, and local-first workflows
- **Systems & networking** — Rust services, async runtimes, protocol codecs, gateways, and simulators
- **Products & interfaces** — dashboards, portfolio systems, operational tools, and the details that make software feel finished

I care about software that is **useful, inspectable, and a little delightful**.

## A few things I believe

> Boring infrastructure is a feature.

> Ship the loop, not just the idea.

> Every useful abstraction should pay rent.
